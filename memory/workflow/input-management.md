# Input Management

Updated: 2026-08-27 (Asia/Seoul)

- Store input values and named Weight presets only in browser-local storage.
- Preserve the built-in recommended Weight set; only user-created presets can be deleted after confirmation.
- Present inputs as a vertical flow and group related fields under compact section headings.
- Weight sections: resource priority, growth rewards, and efficiency modifiers.
- Player Progress is divided into seven color-coded resource cards: Level/LP, Generator, Software Tech, Loop/MP, Shards/Operation, Research/Equipment, and Academy. Generator keeps Manual mk1-8 in a compact nested grid; Software Tech uses its own Auxesia-orange card.
- Input-screen language is browser-local and defaults to Korean; English switches all generic UI copy while preserving game proper nouns. Korean must translate generic labels including Player Progress, Ship Progress, Long Run, Rank, and Crew.
- Ship sections: one responsive card per ship, containing its Rank/Crew pair.
- Do not display the short-number-format helper label beside individual fields.
